# Calorie Blitz 🍽️⚡  
*A Fast & Efficient Calorie Tracking Tool*

Calorie Blitz is a lightweight, high-performance calorie tracking web app built using **HTML, CSS, and JavaScript**. Designed with speed and simplicity in mind, it provides an intuitive and smooth user experience for everyday calorie management.

---

## 🚀 Features

- 📤 **Upload Image** – Seamlessly upload meal photos for calorie analysis  
- 📸 **Capture Photo** – Use your device camera to snap food images on the fly  
- 🎯 **Drag & Drop Support** – Effortlessly drag and drop images for instant tracking  
- 📜 **History Tracking** – View and manage past calorie logs  
- 📂 **Export Data as PDF** – Download your food log as a well-formatted PDF  
- 🔄 **Reset System** – Quickly clear history and start fresh  
- 🌗 **Toggle Dark/Light Theme** – Switch between light and dark modes for comfortable viewing  
- ⚡🧠 **Grok Cloud API Integration** – Enhanced image processing for accurate calorie estimates

---

## 🧠 Powered By

- **HTML5 + CSS3 + JavaScript (Vanilla JS)**
- **Grok Cloud API** – AI-driven food and calorie recognition  
- **FileReader & Canvas API** for image handling and rendering  
- **jsPDF** for PDF export functionality
